台灣房地產市場與總體經濟月度自動化分析系統，結合 Python 資料科學工具與視覺化呈現的練習專案。

## 專案概述
本專案旨在透過自動化分析與資料視覺化，探討相關總體經濟與費用明細趨勢，並作為個人資料分析與程式開發能力的求職作品集展示。

## 專案結構
- `Untitled29.ipynb`：主要的 Python 資料處理與分析 Jupyter Notebook 筆記本。
- `FF練習.docx`：實驗記錄與相關數據分析說明文件。
- `chart_df2.png`：透過 Matplotlib 產出的資料視覺化圖表（差旅費 > 4000 明細金額分析）。

## 使用技術
- **Python** (Pandas, Matplotlib)
- **GitHub** 專案版本控制與作品集展示
